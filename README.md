# itskpflow

Professional portfolio and home of Kalyan Prasad.

Live site: [https://itskpflow.com](https://itskpflow.com)

## Stack

- Next.js 15 and React 19
- Tailwind CSS 4
- MDX content managed with Contentlayer2
- Pliny blog, search, analytics, comments, and newsletter components

## Local development

This repository uses Yarn 3.6.1.

```bash
yarn
yarn dev
```

Create a production build and run it locally with:

```bash
yarn build
yarn serve
```

## Deployment

The repository includes a GitHub Pages workflow that builds and deploys pushes to `main`.

## Redesign

The portfolio redesign is being delivered in stages. Each stage is scoped independently so the working site and deployment remain stable while content and presentation evolve.
